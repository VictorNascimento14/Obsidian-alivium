# JornadaCard

## O que é

Cartão de jornada com situação (Nova / Em andamento / Concluída) e barra de andamento. Usado em
[[Jornadas]] e, depois, no Início.

## Onde está no código

`src/componentes/JornadaCard.tsx`. Recebe o `Andamento` pronto (calculado por `andamento()`).
