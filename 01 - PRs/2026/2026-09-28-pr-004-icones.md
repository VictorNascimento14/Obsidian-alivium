# PR #4 — ui(icones): acrescentar ícones de navegação do Alivium ao Glyph

## 🎯 Contexto

A navegação planejada ([[2026-09-28-plano-da-v1-do-frontend]]) usa destinos que o `Glyph` do kit não
cobria.

## 🔧 Mudanças

- `src/ui/base/Glyph.tsx` — `home`, `book`, `compass`, `pen`, `heart`, `leaf`.

## 🕵️ Dado pessoal (LGPD)

Nenhum.

## 🧠 Decisões técnicas

- **Acrescentar ao `Glyph` em vez de usar Remix na coluna**: a invariante 12 do sistema proíbe as duas
  famílias no mesmo agrupamento visual, e a espessura faz parte da identidade.
- Esta é a única edição feita dentro de `src/ui/`: é extensão prevista pelo próprio kit ("um ícone novo
  é um `path` a mais"), não ajuste de tela.

## 🧪 Como testar

1. `npm run dev`; comparar traçado dos seis com os ícones dos indicadores.
